## 📮 Postman

**Para qué sirve**: Probar y trabajar con APIs (servicios web)

Es como un "navegador para APIs". Cuando desarrollas un backend, usas Postman para enviar peticiones (GET, POST, PUT, DELETE) a tus endpoints y ver qué responden, sin necesidad de crear un frontend primero.

**Ejemplo práctico**: Tienes una API que registra usuarios. Con Postman puedes probar si funciona enviándole datos de prueba antes de conectarla a tu app.

## 🍃 MongoDB Compass

**Para qué sirve**: Ver y administrar bases de datos MongoDB de forma visual

Es la interfaz gráfica de MongoDB. En lugar de escribir comandos en terminal para ver tus datos, puedes explorar tus colecciones, documentos, crear registros y hacer consultas con clicks.

**Ejemplo práctico**: Quieres ver todos los usuarios registrados en tu base de datos MongoDB. Con Compass abres la colección "users" y ves todos los datos como si fuera una tabla.

---

## 🗄️ TablePlus

**Para qué sirve**: Conectarte y administrar múltiples tipos de bases de datos (MySQL, PostgreSQL, SQLite, etc.)

Es como Compass pero para casi cualquier base de datos. Una sola herramienta para ver y editar datos de diferentes bases de datos relacionales y no relacionales.

**Ejemplo práctico**: Tienes un proyecto con PostgreSQL y otro con MySQL. Con TablePlus manejas ambas desde un solo program
