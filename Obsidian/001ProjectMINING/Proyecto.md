Este proyecto está orientado a la implementación de un sistema integral de monitorización en tiempo real y automatización de la trazabilidad en operaciones mineras, específicamente en las áreas de carguío y acarreo de mineral. Utilizando dispositivos GPS ruptela y sensores avanzados, el sistema capturará datos precisos sobre la ubicación y el estado de la maquinaria pesada, incluyendo volquetes, excavadoras(de usara ruptela pro5lite para ller datos propiertaios para saber cuanto a cargado), entre otros para despues generar resportes de cuando estuvo en zonas virtuales definidas

La integración mapbox permitirá visualizar dinámicamente la flota de maquinaria en una plataforma web interactiva, proporcionando una visualización clara y detallada de la ubicación en tiempo real. Además, el sistema generará reportes analíticos kpis y dashboards interactivos para monitorear el rendimiento operacional y facilitar la toma de decisiones.

Los datos recopilados serán almacenados en una base de datos PostgreSQL, garantizando una gestión eficiente, escalable y confiable de la información. Esta infraestructura permitirá el procesamiento de grandes volúmenes de datos, manteniendo altos estándares de seguridad y accesibilidad.

Este proyecto está diseñado para optimizar las operaciones mineras, mejorar la trazabilidad y proporcionar insights operacionales valiosos mediante el uso de tecnologías avanzadas, asegurando la eficiencia y seguridad en los procesos de carguío y acarreo.
