
## Cómo insertar los registros

Puedes hacerlo directamente con SQL en tu base de datos PostgreSQL:

```sql
-- FRENTE (zona de extracción)
INSERT INTO maquinaria (nombre_maquinaria, tipo_maquinaria, latitud, longitud)
VALUES ('Frente1', 'frente', -14.XXXX, -69.XXXX);

-- CHUTE 1
INSERT INTO maquinaria (nombre_maquinaria, tipo_maquinaria, latitud, longitud)
VALUES ('Chute1', 'chute', -14.YYYY, -69.YYYY);

-- CHUTE 2
INSERT INTO maquinaria (nombre_maquinaria, tipo_maquinaria, latitud, longitud)
VALUES ('Chute2', 'chute', -14.ZZZZ, -69.ZZZZ);
```
